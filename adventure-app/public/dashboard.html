🔒 Kiosk child-safety

 
The PIN locks the front-desk "$10 collected — Print" button so kids can't press it. The kiosk itself has no links anywhere else — but to fully lock the tablet, also pin the browser at the device level:
  • iPad: Settings → Accessibility → Guided Access (triple-click to lock to Safari)
  • Android: Settings → Security → App pinning, or a kiosk app like Fully Kiosk
  • Windows/Chromebook: launch Chrome with --kiosk <your kiosk link>
